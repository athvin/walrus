# PR 10.4 — Replace the `LoaderError::Internal` catch-all with named domain variants

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Readiness:** audited · **Outcome:** change
> **Gates:** fmt,clippy,test · **Test packages:** loader

> **Phase:** 10 — Rust error handling · **Crates touched:** `loader` · **Est. size:** M ·
> **Depends on:** PR 10.3 · **Unlocks:** PR 10.5

`LoaderError::Internal(String)` (`error.rs:33`, `#[error("{0}")]`) is constructed **21 times**
outside `error.rs` and collapses genuinely different failures into one variant that all exit 70.
The clusters are mechanical and obvious once listed: *decode registry columns* ×5
(`bootstrap.rs:62,106`; `phase_a.rs:317`; `phase_b.rs:24`; `ddl.rs:369`), *LSN parse* ×3
(`phase_b.rs:75`; `transform.rs:164,168`), *control-txn begin/commit* ×2 (`phase_a.rs:211,216`),
*health bind/join/serve* ×3 (`main.rs:56,159,160`). Each of those has a real underlying error
that is being `format!`-ed away. After this PR they are four named variants — `RegistryDecode`,
`LsnParse`, `ControlTxn`, `Health` — carrying typed payloads and a `#[source]`, and `Internal`
shrinks to the ≤8 sites where the failure genuinely *is* "an invariant we asserted does not
hold".

## Why — learning objectives

- **Failure modes as enum data, not formatted strings** — a variant name is machine-matchable; a
  `format!` prefix is a regex waiting to rot.
- **Choosing the payload** — `&'static str` for a fixed operation label, `String` for a runtime
  table name, `#[source]` for the real cause; never all three squashed into one message.
- **Exhaustive matches with no wildcard arm** — `as_common` deliberately has no `_ =>`, so every
  new variant is a compile error until it is explicitly classified. Adding four variants
  exercises that.
- **The loader's phase structure** — schema-registry decode, Phase-B LSN watermarks, and the
  lease/health bootstrap are three different blast radii that deserve three different names.

// crates/loader/src/error.rs
#[derive(Debug, thiserror::Error)]
pub enum LoaderError {
    // … existing variants (Config, Control, Duck, ObjectStore, LeaseContended,
    //    CorruptCheckpoint, Quarantine, EpochBumped) …

    /// A `schema_registry.columns` payload did not decode into a `PgRelation`. The sink only ever
    /// writes a serialised `PgRelation`, so this is a data-integrity bug, not a cold dependency.
    #[error("decode registry columns for {table} v{version}")]
    RegistryDecode {
        table: String,
        version: i64,
        #[source]
        source: serde_json::Error,
    },

    /// A stored LSN string failed to parse. `field` names WHICH watermark.
    #[error("parse {field} as an LSN")]
    LsnParse {
        field: &'static str,
        #[source]
        source: common::LsnParseError,
    },

    /// A control-DB transaction could not be begun or committed.
    #[error("control transaction: {op}")]
    ControlTxn {
        op: &'static str,
        #[source]
        source: sqlx::Error,
    },

    /// The health/metrics server failed to bind, join or serve.
    #[error("health server: {op}")]
    Health {
        op: &'static str,
        #[source]
        source: Box<dyn std::error::Error + Send + Sync + 'static>,
    },

    /// An asserted invariant does not hold. Kept for the ≤8 sites with no wrapped cause.
    #[error("{0}")]
    Internal(String),
}

            LoaderError::Internal(m) => common::Error::Internal(m.clone()),

## Hints & gotchas

- **`anyhow::Error` does not implement `std::error::Error`**, so it cannot sit behind `#[source]`
  directly. That is why `Health.source` is `Box<dyn std::error::Error + Send + Sync + 'static>` —
  `anyhow::Error` converts into exactly that via `.into()`, and `io::Error`/`JoinError` via
  `Box::new`.
- **Partial moves bite at `bootstrap.rs:62`.** `serde_json::from_value(row.columns)` moves a
  field out of `row`; bind `table` from `row.source_schema`/`row.source_table` *before* that line
  or the closure will not borrow-check.
- **`main.rs:159` and `:160` are chained `map_err`s on the same expression** — the outer is the
  `JoinError` from `tokio::spawn`, the inner is the task's own `anyhow::Result`. They need
  different `op` labels, not one shared variant instance.
- **The `ControlTxn` remap is behaviour, not cosmetics.** Exit 11 vs 70 is what a runbook greps;
  put it in the PR body and pin it in a test so a future reader sees it was chosen.
- **`LsnParseError` is already a `thiserror` struct error** carrying `input` and `reason` — do
  not re-stringify it into the variant's message; `#[source]` plus `field` is enough.
- **`#[error("…")]` messages stay lowercase and unpunctuated** (see PR 10.7's convention) —
  `"parse {field} as an LSN"`, not `"Failed to parse LSN."`.
- **`unwrap`/`expect` are denied in production**; the sibling `error_test.rs` may use them.
  `crates/loader/src/error_test.rs` is wired via `#[cfg(test)] #[path = …] mod tests;` — never an
  inline `mod tests { }`.
- **DuckDB cold builds are slow** (bundled engine compiles from source: ~20 min cold, ~3 min
  cached). Budget for it when you push and wait for CI rather than re-triggering.
