# PR 16.2 — Replace hot-path slice indexing with slice patterns in the decoder and Arrow builder

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Readiness:** audited · **Outcome:** change
> **Gates:** fmt,clippy,test · **Test packages:** pg-sink,pg-to-arrow

> **Phase:** 16 — Rust compiler optimization · **Crates touched:** `pg-sink`, `pg-to-arrow` ·
> **Est. size:** M · **Depends on:** PR 16.1 · **Unlocks:** PR 16.3

**31 expressions in walrus's two benchmarked modules index or slice with panicking `[]`.**
`crates/pg-sink/src/pgoutput/reader.rs` has **7**: every primitive re-indexes `self.buf` *right
after* its own `need()` bounds check (`reader.rs:59, 71, 89, 108, 127, 129, 148`) — a second,
provably-redundant check, and in `int16`/`int32`/`int64` a `try_into().map_err(…)` whose error arm
`need()` already proved unreachable. `crates/pg-to-arrow/src/batch.rs` has **24**: the `append_row`
flat-builder cursor (`self.builders[bi]` / `fields[bi]` on six lines, `batch.rs:154-188`) plus the
Tier-2 fan-out helpers, which index the constants `0..4` into slices whose width they already know
(`batch.rs:421-501`), one multirange field lookup, and two timestamp suffix slices. The latter three
are not the target optimization, but must use total accessors because the lint is module-wide. These
are the **236 ns/row `parse_tuple`** and
**460 ns/row `append_row`** paths from `docs/benchmarks.md`. After this PR both files carry
`#![deny(clippy::indexing_slicing)]` and the count is 0 — every one of those latent panics is either
gone (the width is in the type) or promoted to a modelled error.

## Why — learning objectives

- **Irrefutable slice patterns, `split_at_mut_checked`, `first_chunk`, `chunks_exact`** — and how a
  bounds check becomes *provably* redundant: once `first_chunk::<4>()` hands you a `&[u8; 4]`, the
  length lives in the type and no later access can check it again.
- **The pgoutput wire cursor and the Arrow Tier-2 fan-out widths (1/3/2/5/1)** that `append_row`
  walks — the whole `bi += 3` / `bi += 5` cursor dance exists only because the widths are written as
  literals instead of being carried by the slice split.

**In scope**

- `crates/pg-sink/src/pgoutput/reader.rs`: add `#![deny(clippy::indexing_slicing)]`; change `need`
  to return the checked head (`Result<&'a [u8], DecodeError>`) so callers never re-check; rewrite
  `byte1`/`int16`/`int32`/`int64`/`string`/`slice` in terms of `first_chunk::<N>()`,
  `split_at_checked`, and `get(..n)`; keep `str`/`take` delegating to `slice`.
- `crates/pg-to-arrow/src/batch.rs`: add `#![deny(clippy::indexing_slicing)]`; give `Emit` a
  `width()` method (the 1/3/2/5/1 literals, in one place); walk `append_row` with
  `split_at_mut_checked` / `split_at_checked` instead of a `bi` counter; destructure each fan-out
  helper's slice with `let [a, b, c] = builders else { … }`. Replace the module's remaining
  multirange-field and timestamp-suffix indexes with checked accessors so the module-wide deny is
  green.
- Behaviour must be **byte-identical**: the same values decoded, the same `DecodeError` /
  `pg_to_arrow::Error` payloads, the same `Display` strings.

**Explicitly deferred** (do *not* build these here)

- The deny is scoped to the two benchmarked modules. Indexing in
  `crates/pg-to-arrow/src/geometric.rs`, `crates/pg-to-arrow/src/tier2.rs`,
  `crates/pg-sink/src/replication.rs` and `crates/pg-sink/src/reload_signal.rs` is left alone.
- No `unsafe`, no `get_unchecked`, no `cargo asm` / assembly inspection.
- **Do not consolidate the error constructors.** `crates/pg-sink/src/pgoutput/reader.rs` builds
  `DecodeError::UnexpectedEof { … }` at exactly **five** sites today (`:34, 56, 70, 84, 104`);
  PR 16.5 is the ticket that collapses them into one `#[cold] #[inline(never)] fn eof(…)`, and
  `grep -c 'UnexpectedEof {' crates/pg-sink/src/pgoutput/reader.rs` = 5 is *its* probe. Keep the
  count at five: `need` keeps its constructor (and stays shared by `byte1` and `take`),
  `int16`/`int32`/`int64`/`string` keep one each.
- No `#[inline]`, `#[cold]` or `#[inline(never)]` attributes — PRs 16.3/16.5/16.6 own those.

**Conflict — the rule offers an escape hatch you may not use.** `opt-bounds-check` presents
`get_unchecked` (behind `unsafe`) as the way to drop a proven-redundant check. **Forbidden here:**
walrus has zero `unsafe` in production and Phase 12 adds `#![forbid(unsafe_code)]`. Resolution:
safe forms only — `let [a, b, c] = slice else { return Err(..) }`, `split_at_mut_checked`,
`first_chunk::<N>()`, `chunks_exact`. That constraint is a feature, not a tax: it converts today's
latent panics into modelled errors instead of trading them for undefined behaviour.

```rust
// crates/pg-sink/src/pgoutput/reader.rs — module top (inner attribute, above the `//!` docs is
// also fine; keep it adjacent to the module doc so the reason is visible).
#![deny(clippy::indexing_slicing)] // PR 16.2: this module is the 236 ns/row parse_tuple path —
                                   // every access must carry its own proof, not a second check.

impl<'a> Reader<'a> {
    /// The unread tail. `pos` only ever advances past bytes a successful read proved were there,
    /// so `get(..)` can never be `None` — writing it this way is what lets the module deny
    /// `indexing_slicing` without an `unsafe` escape hatch.
    fn rest(&self) -> &'a [u8] {
        todo!("self.buf.get(self.pos..) — total, with an empty-slice fallback")
    }

    /// Error unless at least `n` bytes remain — and hand *those bytes back*, so the caller never
    /// bounds-checks a second time. (Keeps the one `UnexpectedEof` constructor `byte1` and `take`
    /// share; PR 16.5 marks it `#[cold]`.)
    fn need(&self, n: usize) -> Result<&'a [u8], DecodeError> {
        self.rest().get(..n).ok_or(DecodeError::UnexpectedEof {
            needed: n,
            offset: self.pos,
            remaining: self.remaining(),
        })
    }

    /// One byte (a `Byte1` type tag or an `Int8`).
    pub fn byte1(&mut self) -> Result<u8, DecodeError> {
        // `need(1)` is the only bounds check and returns exactly that byte; `first()` on a slice
        // it just proved is one byte long can only be `Some`, so the fallback arm is dead code —
        // the same "avoid an infallible unwrap" idiom as `BatchBuilder::append_meta`
        // (crates/pg-to-arrow/src/batch.rs:171-175). It adds no new error site.
        let b = todo!("self.need(1)? -> first().copied(), with the dead arm spelled out totally");
        self.pos += 1;
        Ok(b)
    }

    /// Big-endian `Int32` (OID / xid). `int16` and `int64` take the same shape with 2 / 8.
    pub fn int32(&mut self) -> Result<u32, DecodeError> {
        // `first_chunk::<4>()` yields `&[u8; 4]`: the width is now in the *type*, so the old
        // `need(4)? ; self.buf[pos..pos+4].try_into().map_err(…)` pair collapses to one check and
        // the `try_into` error arm — which `need` had already proved unreachable — disappears.
        let Some(&arr) = self.rest().first_chunk::<4>() else {
            return Err(DecodeError::UnexpectedEof {
                needed: 4,
                offset: self.pos,
                remaining: self.remaining(),
            });
        };
        self.pos += 4;
        Ok(u32::from_be_bytes(arr))
    }

    /// A null-terminated UTF-8 `String`.
    pub fn string(&mut self) -> Result<String, DecodeError> {
        let start = self.pos;
        let tail = self.rest();
        let Some(rel) = tail.iter().position(|&b| b == 0) else {
            return Err(DecodeError::UnexpectedEof {
                needed: 1,
                offset: start,
                remaining: self.remaining(),
            });
        };
        // `position` proved `rel < tail.len()`, so this split is total.
        let (text, _nul_and_rest) = todo!("tail.split_at_checked(rel) — keep the `?`-free path");
        let s = std::str::from_utf8(text)?.to_string();
        self.pos = start + rel + 1; // consume the NUL terminator
        Ok(s)
    }

    /// Borrow `n` bytes, advancing the cursor; `str` and `take` keep delegating here.
    pub fn slice(&mut self, n: usize) -> Result<&'a [u8], DecodeError> {
        let out = self.need(n)?;
        self.pos += n;
        Ok(out)
    }
}
```

```rust
// crates/pg-to-arrow/src/batch.rs — module top.
#![deny(clippy::indexing_slicing)] // PR 16.2: the 460 ns/row append_row path.

impl Emit {
    /// How many flat builders this shape consumes. These are the 1/3/2/5/1 widths that
    /// `emit_kind`'s doc comment says "are how `append_row` advances the flat builder cursor" —
    /// written once here instead of as six literals inside the loop.
    const fn width(&self) -> usize {
        match self {
            Emit::Scalar | Emit::Multirange | Emit::Geometric(_) => 1,
            Emit::Interval => 3,
            Emit::Timetz => 2,
            Emit::Range => 5,
        }
    }
}

impl BatchBuilder {
    pub fn append_row(&mut self, values: &[TupleValue], meta: &SinkMeta) -> Result<(), Error> {
        if values.len() != self.plan.len() {
            return Err(Error::RowLenMismatch {
                expected: self.plan.len(),
                got: values.len(),
            });
        }
        // Clone the Fields (Arc) so we can read the field types while mutably borrowing `builders`.
        let fields = self.schema.fields().clone();
        // Two cursors that *carry* their remaining width instead of an integer `bi` that has to be
        // re-validated on every access.
        let mut builders: &mut [Box<dyn ArrayBuilder>] = &mut self.builders;
        let mut flds: &[FieldRef] = &fields;
        for (emit, value) in self.plan.iter().zip(values) {
            let w = emit.width();
            // `std::mem::take` lets the loop hand `builders` back to itself: `&mut [T]` implements
            // `Default` (the empty slice), so the reborrow does not outlive the iteration.
            let (bs, b_rest) = std::mem::take(&mut builders)
                .split_at_mut_checked(w)
                .ok_or_else(|| todo!("a modelled error — the plan/schema widths disagree"))?;
            let (fs, f_rest) = flds
                .split_at_checked(w)
                .ok_or_else(|| todo!("same, for the field list"))?;
            match emit {
                Emit::Scalar => {
                    let ([b], [f]) = (bs, fs) else { todo!("width() == 1 proved this") };
                    append_value(b.as_mut(), f, value)?;
                }
                Emit::Interval => append_interval(bs, todo!("fs[0].name() without indexing"), value)?,
                Emit::Timetz => append_timetz(bs, todo!("same"), value)?,
                Emit::Range => append_range(bs, fs, value)?,
                Emit::Multirange => { todo!("as Scalar, then append_multirange") }
                Emit::Geometric(kind) => { todo!("as Scalar, then append_geometric(.., *kind)") }
            }
            builders = b_rest;
            flds = f_rest;
        }
        self.append_meta(meta)?;
        self.rows += 1;
        Ok(())
    }
}
```

## Hints & gotchas

- **MSRV is pinned to stable 1.95.0** (`rust-toolchain.toml:4`) and CI has an `msrv` job. Everything
  this PR needs is older than that: `first_chunk` (1.77), `split_at_checked` /
  `split_at_mut_checked` (1.80), `let … else` (1.65). Do not reach for anything newer.
- The `std::mem::take(&mut builders)` trick in `append_row` is load-bearing: `&mut [T]` implements
  `Default` as the empty slice, which is what lets you reassign a `&mut` slice cursor inside a loop
  without fighting the borrow checker. Without it you will get "cannot borrow `*builders` as mutable
  more than once".
- `clippy::indexing_slicing` is a **restriction** lint — not in `clippy::all`, so the workspace
  `all = "deny"` at `Cargo.toml:16` does not cover it and a module-level `#![deny(...)]` is the
  right scope. Do not promote it workspace-wide: `geometric.rs`, `tier2.rs` and the loader index
  freely and are not on a benchmarked path.
- `batch.rs` pulls in its unit tests with `#[cfg(test)] #[path = "batch_test.rs"] mod tests;` at the
  bottom of the file, so a module-level `#![deny]` reaches them too. `batch_test.rs` has zero
  indexing today, so it should pass untouched — if a future test needs indexing, put
  `#[allow(clippy::indexing_slicing)]` on the `mod tests;` line, not on the whole module.
  `reader.rs` also pulls in `reader_test.rs`; it has no indexing and remains untouched. Its broader
  coverage is `crates/pg-sink/tests/pgoutput_vectors.rs`.
- `arrow-rs`'s `Field::name()` returns `&String`, and `Fields` derefs to `&[FieldRef]` — so
  `self.schema.fields().clone()` is an `Arc` bump, not a deep copy. Keep that clone: it is what
  lets you read field types while `self.builders` is mutably borrowed.
- The golden vectors in `crates/pg-sink/tests/pgoutput_vectors.rs` pin the **error payloads**
  (`needed` / `offset` / `remaining`), not just the happy path. If a rewrite shifts `offset` by one
  the vectors will tell you — do not "fix" the vector.
- `unwrap`/`expect` are `deny` in production (`Cargo.toml:20-21`). Every `else` arm added here must
  return a real `DecodeError` / `Error` variant, or be a genuinely-total destructure.
- Re-running `cargo bench -p pg-sink --bench decode` / `-p pg-to-arrow --bench batch` is optional
  here and **not** a gate — benches are never a CI gate (`docs/benchmarks.md:4-6`). PR 16.3 is the
  ticket that records a measured delta.
- Do not touch any `.sql` file or the committed `.sqlx` offline cache — there is no Docker on this
  machine to regenerate it.
