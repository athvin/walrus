# PR 25.4 — Gate the clone-before-move discipline with clippy::redundant_clone

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Phase:** 25 — Rust closures · **Crates touched:** `loader`, `pg-sink` · **Est. size:** S ·
> **Depends on:** PR 25.3 · **Unlocks:** PR 25.5

walrus already follows `closure-move-capture` exactly, and the evidence is unusually clean: all
**16** production `async move` blocks and both production `move |…|` closures capture *only*
explicitly pre-bound locals — **zero** of the 18 bodies mentions `self.`, and `self.clone()` is
**0** repo-wide in production. `reload.rs:406-421` binds eight locals (pool, holder, ttl, child
token, export config, source URL, waiters, sink) before the `tokio::spawn(async move …)` at :424;
`compaction.rs:71-73` clones the cancellation token into `watch` precisely so the original `cancel`
stays usable by `full_rebuild`. Nothing prevents the next spawn from being written as
`tokio::spawn(async move { self.pool… })`. This PR turns the convention into a gate: confirm
`clippy::redundant_clone` is denied in `[workspace.lints.clippy]` (`Cargo.toml:15-21`), and add the
closure-specific regression guard no lint provides — a source scan asserting that no production
`move` body reaches through `self`.

## Why — learning objectives

- **`move` closures and `'static` task captures** — `tokio::spawn` needs `'static`, so `move` is
  mandatory; the design question is *what* gets moved, and the answer is "the fields, cloned, not
  the struct".
- **Clone selectively so the original stays usable** — `compaction.rs`'s
  `let watch = cancel.clone();` exists solely so `cancel` survives for the caller. Deleting that
  clone would compile only after you also broke the abort contract.
- **Lints vs guards** — `redundant_clone` proves a clone was *unnecessary*; nothing proves a capture
  was *too broad*. The second needs a written guard, which is what makes this an enforce ticket.
- **walrus's spawn preludes** — lease renewal (`loader/src/lease.rs:32-56`), the lease-guarded
  exporter task (`pg-sink/src/reload.rs:405-467`), and the drain watcher that interrupts a running
  DuckDB rewrite (`loader/src/compaction.rs:66-80`).

**Conflict — resolve it explicitly; do not apply the rule blind.**
`clippy::redundant_clone` is claimed by **three** tickets that run before this one:
`phase-9-rust-ownership/pr-9.1-own-borrow-over-clone.md` (adds the deny + fixes both sites),
`phase-11-rust-memory/pr-11.7-mem-take-replace.md` (adds the deny again), and Phase 34's
`anti-clone-abuse`. Phase 25 owns the *closure-side* enforcement, not the lint's first landing.
So **step 0 of this PR is to re-measure**, and the outcome decides the diff:

- `grep -n 'redundant_clone' Cargo.toml` — **absent** → add `redundant_clone = "deny"` under
  `[workspace.lints.clippy]` with a comment, and fix whichever of the two sites still report.
- **present** (the expected case, PR 9.1 landed it) → do **not** add it twice and do **not** touch
  `duck.rs:118` / `snapshot_test.rs:91`; the deliverable is then only the guard below, plus the
  guard's own assertion that the deny is still there so a later phase cannot quietly drop it.

Either way this PR must not end up empty: the guard is unconditional.

**In scope**

- `crates/pg-sink/tests/move_capture_discipline.rs` — a std-only source-scan guard over
  `crates/*/src/**/*.rs` (excluding `*_test.rs`) that asserts:
  1. no production `async move { … }` block or `move |…|` closure body contains `self.`;
  2. `self.clone()` appears **0** times in production;
  3. `[workspace.lints.clippy]` in the workspace `Cargo.toml` denies `redundant_clone`;
  4. the walker actually walked — it found **≥ 16** `async move` blocks and **≥ 2** `move |`
     closures, so an empty scan cannot pass silently;
  5. the checker is tested in both directions against synthetic snippets.
- `Cargo.toml` — add `redundant_clone = "deny"` **only if step 0 finds it absent**.

**Explicitly deferred** (do *not* build these here)

- `clippy::clone_on_ref_ptr`. It would rewrite every `Arc` clone in the spawn preludes into
  `Arc::clone(&x)`, and its site count cannot be measured from the committed evidence. Phase 9's
  `own-arc-shared` owns that decision.
- Restructuring `lease::spawn_renewer`'s six by-value parameters into an owned bundle. It is a
  different (and legitimate) shape, not a violation.
- The e2e harness (`tests/e2e`) and the benches. Production surface only — the harness deliberately
  clones freely and carries file-level allows.
- No production capture is *changed* by this PR. If the guard flags something, the tree changed
  under you: re-measure before rewriting anything.
- No new dependency. No `regex`, no `walkdir` — hand-roll ~80 lines of `str` scanning.

## Hints & gotchas

- **Re-measure before you write a line.** Three earlier tickets touch `redundant_clone` and two of
  them add the same `Cargo.toml` key. A duplicate key in a TOML table is a hard parse error, so
  "just add it" will break the workspace build, not merely duplicate a line.
- **`redundant_clone` is a nursery lint with a false-positive history** and MIR-dependent results —
  a toolchain bump can change what it reports. If it fires spuriously in a later phase, scope the
  deny to the five member crates rather than reverting the gate; a removed gate never comes back.
- **Brace matching must skip strings and comments.** The loader and pg-sink are full of SQL string
  literals; a naive depth counter that sees `"{table}"` is fine (balanced) but `'{'` or a lone `"{"`
  is not. Skip `"…"` (honouring `\"`), `r"…"`/`r#"…"#`, `'…'` and `//` to end-of-line.
- **`self.` is the signal, not `self`.** Matching bare `self` would flag `Self::` paths and the word
  inside doc comments. Match a field/method access — `self` followed by optional whitespace and `.`
  — and strip comments before checking.
- **Do not add `regex` or `walkdir`.** Every new dependency must clear `cargo deny` (advisories, the
  8-license allow-list, bans) for ~80 lines of `str` scanning that std already does.
- **`CARGO_MANIFEST_DIR` is the only reliable anchor.** `cargo test` sets the CWD to the package root
  for integration tests, but do not rely on it — `env!("CARGO_MANIFEST_DIR")` is resolved at compile
  time and is exactly `<repo>/crates/pg-sink`.
- **Integration tests under `tests/` are not covered by `clippy.toml`'s
  `allow-unwrap-in-tests`/`allow-expect-in-tests`.** That is why every existing file there carries a
  file-level `#![allow(clippy::unwrap_used, clippy::expect_used)]`. Copy the header, comment and all.
- `warnings = "deny"` is inherited via `[lints] workspace = true`, so an unused helper in the guard
  file is a hard error. Delete scaffolding as you go.
- Report **all** violations at once (collect into a `Vec`, assert empty). A gate that reports one
  problem per run is a gate people learn to hate.
- **Do not touch `.sql` files or the `.sqlx` offline cache** — no Docker locally to regenerate it.
