# PR 25.4 — Gate the clone-before-move discipline with clippy::redundant_clone

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Readiness:** audited · **Outcome:** change
>
> **Gates:** fmt,clippy,test · **Test packages:** pg-sink

> **Phase:** 25 — Rust closures · **Crates touched:** `loader`, `pg-sink` · **Est. size:** S ·
> **Depends on:** PR 25.3 · **Unlocks:** PR 25.5

At baseline `83faada`, walrus already follows `closure-move-capture` exactly, and the evidence is
unusually clean: all **15** production `async move` blocks (loader 6, pg-sink 9) and both production
`move |…|` closures (pg-sink 2) capture *only* explicitly pre-bound locals — **zero** of the 17
bodies mentions `self.`, and `self.clone()` is **0** repo-wide in production. The authored survey's
16-block floor became 15 when PR 14.4 removed two bootstrap `async move` callbacks and PR 14.16
added one loader epoch watcher. `reload.rs:544-557` binds nine field-derived values (pool, holder,
ttl, restart cap, child token, export config, source URL, waiters, sink) before the
`exporters.spawn(async move …)` at :562; `compaction.rs:87-88` clones the cancellation token into
`watch` precisely so the original `cancel` stays usable by `full_rebuild`. Nothing prevents the
next spawn from being written as
`tokio::spawn(async move { self.pool… })`. This PR turns the convention into a gate: confirm
`clippy::redundant_clone` is denied in `[workspace.lints.clippy]` (`Cargo.toml:35,136-137`), and add the
closure-specific regression guard no lint provides — a source scan asserting that no production
`move` body reaches through `self`.

## Why — learning objectives

- **`move` closures and `'static` task captures** — `tokio::spawn` needs `'static`, so `move` is
  mandatory; the design question is *what* gets moved, and the answer is "the fields, cloned, not
  the struct".
- **Clone selectively so the original stays usable** — `compaction.rs`'s
  `let watch = cancel.clone();` exists solely so `cancel` survives for the caller. Deleting that
  clone would compile only after you also broke the abort contract.
- **Lints vs guards** — `redundant_clone` proves a clone was *unnecessary*; nothing proves a capture
  was *too broad*. The second needs a written guard, which is what makes this an enforce ticket.
- **walrus's spawn preludes** — lease renewal (`loader/src/lease.rs:59-83`), the lease-guarded
  exporter task (`pg-sink/src/reload.rs:538-599`), and the drain watcher that interrupts a running
  DuckDB rewrite (`loader/src/compaction.rs:81-94`).

## Hints & gotchas

- **Re-measure before you write a line.** The expected branch is one `redundant_clone` key, 15
  production `async move` blocks, and 2 production `move |…|` closures. A duplicate key in a TOML
  table is a hard parse error, so "just add it" will break the workspace build, not merely duplicate
  a line.
- **`redundant_clone` is a nursery lint with a false-positive history** and MIR-dependent results —
  a toolchain bump can change what it reports. If it fires spuriously in a later phase, scope the
  deny to the five member crates rather than reverting the gate; a removed gate never comes back.
- **Brace matching must skip strings and comments.** The loader and pg-sink are full of SQL string
  literals; a naive depth counter that sees `"{table}"` is fine (balanced) but `'{'` or a lone `"{"`
  is not. Skip `"…"` (honouring `\"`), `r"…"`/`r#"…"#`, `'…'` and `//` to end-of-line.
- **`self.` is the signal, not `self`.** Matching bare `self` would flag `Self::` paths and the word
  inside doc comments. Match a field/method access — `self` followed by optional whitespace and `.`
  — and strip comments before checking.
- **Do not add `regex` or `walkdir`.** Every new dependency must clear `cargo deny` (advisories, the
  8-license allow-list, bans) for ~80 lines of `str` scanning that std already does.
- **`CARGO_MANIFEST_DIR` is the only reliable anchor.** `cargo test` sets the CWD to the package root
  for integration tests, but do not rely on it — `env!("CARGO_MANIFEST_DIR")` is resolved at compile
  time and is exactly `<repo>/crates/pg-sink`.
- **Integration tests under `tests/` are not covered by `clippy.toml`'s
  `allow-unwrap-in-tests`/`allow-expect-in-tests`.** That is why every existing file there carries a
  file-level `#![allow(clippy::unwrap_used, clippy::expect_used)]`. Copy the header, comment and all.
- `warnings = "deny"` is inherited via `[lints] workspace = true`, so an unused helper in the guard
  file is a hard error. Delete scaffolding as you go.
- Report **all** violations at once (collect into a `Vec`, assert empty). A gate that reports one
  problem per run is a gate people learn to hate.
- **Do not touch `.sql` files or the `.sqlx` offline cache** — no Docker locally to regenerate it.
