PR 9.7 already owns the `TupleValue`, `SinkMeta`, `common::Error`, and `pgoutput::Message` size ceilings. This residual task adds exact 64-bit layout ratchets only for the hot types that PR 9.7 did not cover.

## Why — learning objectives

- Distinguish a ceiling owned by an optimization policy from an exact layout snapshot.
- Keep each assertion next to the type whose per-row or per-frame cost it protects.
