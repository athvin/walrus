# PR 27.11 — Make the enum variant the single source of truth for its SQL literal

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Readiness:** audited · **Outcome:** change
>
> **Gates:** fmt,clippy,test · **Test packages:** control

> **Phase:** 27 — Rust naming conventions · **Crates touched:** `control` ·
> **Est. size:** M · **Depends on:** PR 27.10 · **Unlocks:** PR 27.12

All **181** production enum variants are UpperCamelCase — **zero** violations, so the headline form
of this rule is already satisfied. The real hazard runs the other way. The four control-plane enums
that map to SQL text — `ManifestKind`, `ManifestStatus` (`crates/control/src/manifest.rs:23,60`) and
`ReloadFlavor`, `ReloadStatus` (`crates/control/src/reload.rs:28,59`) — each hand-write their literal
**twice**: once in an exhaustive `as_str()` match, once in a `from_str()` match that ends in an
`other => Err(..)` catch-all. That is **13** `=> Ok(..)` arms across the two files (6 + 7). Adding a
variant breaks `as_str` at compile time and then *silently* drops out of `from_str` — the value the
sink writes becomes a value the loader cannot read. This PR gives each enum a
`pub const ALL: &[Self]`, rewrites `from_str` as a scan over it, and moves both sibling test files
off their hard-coded variant lists onto `ALL`.

## Why — learning objectives

- **Associated consts as a single source of truth vs. duplicated match arms** — one exhaustive
  `match` (compile-checked) plus one `ALL` slice (the enumeration) beats two parallel matches that
  the compiler only checks in one direction. `common::metrics::names::LOADER_ALL`
  (`crates/common/src/metrics.rs:121`) is the in-tree precedent: a const slice that tests iterate
  instead of restating.
- **The `file_manifest.kind`/`status` and `table_reload.status` contract** — `table_reload` has real
  CHECK constraints (`migrations/control/0004_table_reload.sql:26,28`) listing every legal literal;
  `file_manifest` has only a **comment** (`migrations/control/0001_control_schema.sql:30,35`), so
  for `ManifestKind`/`ManifestStatus` the Rust literal *is* the whole contract. That asymmetry
  decides how each of the two test files is written.

**In scope**

- Add `pub const ALL: &[Self]` to each of the four enums, in persisted order, with a doc comment
  stating it is the parse-side source of truth and that a new variant must be listed here as well
  as in `as_str`.
- Rewrite all four `FromStr::from_str` bodies as
  `Self::ALL.iter().copied().find(|v| v.as_str() == s).ok_or_else(|| format!(…))`, keeping the error
  message text **byte-identical** to today's (`"unknown manifest kind: {s}"`, etc.). This removes all
  13 `=> Ok(..)` arms.
- `crates/control/src/manifest_test.rs`: drive the round-trip loops off `ALL`; keep **one** explicit
  assertion pinning the exact literal strings, because `file_manifest.kind`/`status` have no CHECK
  constraint and a silent rename would otherwise be invisible.
- `crates/control/src/reload_test.rs`: drive the round-trip loops off `ALL`, and add a cross-check
  against `include_str!("../../../migrations/control/0004_table_reload.sql")` in **both**
  directions — every `ALL` literal appears in the CHECK, and every literal the CHECK admits parses.
  The second direction is what catches a variant added to the enum and the migration but forgotten
  in `ALL`.
- Add the `rename_all` assertion described under the conflict below.

**Conflict — resolve it explicitly, do not apply the rule blindly**

`ReloadFlavor` and `ReloadStatus` also `#[derive(sqlx::Type)]` with
`#[sqlx(rename_all = "lowercase")]` / `#[sqlx(rename_all = "snake_case")]` — a **third** spelling of
each literal, and the one `query_file_as!(ReloadRow, …)` actually uses when decoding a row. Do
**NOT** delete those derives to "collapse to one source of truth": removing them changes the decode
path for every `table_reload` query and there is no Docker on this machine to regenerate the
committed `.sqlx` offline cache. Instead, **pin the third spelling with an assertion**: encode each
variant through `sqlx::Encode<Postgres>` into a `PgArgumentBuffer` and assert the bytes equal
`as_str()`. The comment at `crates/control/src/reload_test.rs:6-7` already *claims* the test covers
all three spellings; this PR makes that true.

**Explicitly deferred** (do *not* build these here)

- **No `.sql` file and no `.sqlx` cache entry is touched.** The migration is read with `include_str!`
  and never modified.
- **No new dependency** — no `strum`, no `enum-iterator`. `ALL` is a hand-written const slice, and
  that is deliberate: it is the visible place a new variant has to be added, and any new dep would
  also have to clear `cargo deny`'s 8-license allow-list.
- No changes to `pg_sink::sink::FileKind` (the re-export of `ManifestKind` at
  `crates/pg-sink/src/sink.rs:27`) or to any consumer — this PR is additive plus two rewritten
  function bodies, so nothing downstream needs editing.
- No `#[non_exhaustive]` on these enums (an `api-` phase question), and no variant renames.

impl ManifestKind {
    /// Every variant, in persisted order — the **parse-side source of truth**: [`FromStr`] scans
    /// this slice, so a variant missing here is a value the loader can write but never read back.
    /// A new variant must be added HERE as well as to `as_str`'s match (the compiler checks that
    /// one; it cannot check this one).
    pub const ALL: &[Self] = &[Self::Snapshot, Self::Stream, Self::Spill, Self::Reload];

    /// The exact `file_manifest.kind` string persisted in the control DB.
    pub fn as_str(self) -> &'static str {
        // unchanged — the exhaustive match stays, and stays the only place the literal is written
        todo!("unchanged")
    }
}

impl std::str::FromStr for ManifestKind {
    type Err = String;

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        todo!(
            "Self::ALL.iter().copied().find(|k| k.as_str() == s) \

fn reload_status_all_matches_the_check_constraint() {
    // Forward: every variant walrus can write is admitted by the DB.
    for st in ReloadStatus::ALL.iter().copied() {
        assert!(
            check_values(RELOAD_MIGRATION, "status").iter().any(|v| v == st.as_str()),
            "{st:?} ({}) is not in the table_reload CHECK", st.as_str()
        );
    }
    // Reverse: every value the DB admits is reachable through ALL. THIS is the direction that
    // catches a variant added to the enum + migration but forgotten in ALL.

        assert!(v.parse::<ReloadStatus>().is_ok(), "CHECK admits {v:?}, FromStr rejects it");
    }

## Hints & gotchas

- Write `pub const ALL: &[Self]`, **not** `&'static [Self]`. `clippy::redundant_static_lifetimes` is
  a `style` lint, so it is inside the `clippy::all = "deny"` walrus has had since PR 7.7 — an
  explicit `'static` on a const will fail the build. Elision already gives you `'static` here.
- `ALL` needs `Copy` to be useful: `Self::ALL.iter().copied()` only compiles because all four enums
  derive `Copy`. They do — do not remove it.
- Keep the error strings identical. `ControlError::Decode(String)` carries them into logs and the
  `is_terminal()` classification; a reworded message is a silent behaviour change for anyone
  grepping operator logs.
- `include_str!` paths are **source-file relative**, so from `crates/control/src/reload_test.rs` the
  migration is `../../../migrations/control/0004_table_reload.sql`. Precedent:
  `crates/pg-sink/tests/reload_signal.rs:22-23`.
- The CHECK text is `CHECK (flavor IN ('reload', 'resync'))` on one line and the `status` one wraps
  across `0004_table_reload.sql:27-28`. Parse from the `IN (` after the column name to the next
  `)`, and trim both whitespace and `'` — do not assume single-line.
- If `PgArgumentBuffer::default()` turns out not to be constructible from outside sqlx, do **not**
  add a dependency or a feature to work around it: drop `rename_all_agrees_with_as_str`, keep the
  bidirectional CHECK cross-check (which pins the same contract through the database's own value
  list), and say so in the PR body.
- `ALL`'s completeness is **not** compiler-checked — that is the honest cost of not taking a
  `strum` dependency. The mitigations are the doc comment on `ALL`, the exhaustive `as_str` match
  (which forces the author into the right file), and the reverse CHECK cross-check for the two
  reload enums. Say this in the doc comment; do not claim more than it delivers.
- Unit tests are **sibling files** (`manifest_test.rs`, `reload_test.rs`, wired by
  `#[cfg(test)] #[path = …] mod tests;`), never inline `mod tests {}`. `clippy.toml` re-allows
  `unwrap`/`expect` there; production code in `control` may use neither.
- Do not touch any `.sql` file or the committed `.sqlx` offline cache — there is no Docker on this
  machine to regenerate it, and `cargo sqlx prepare --check` runs in the CI integration job.
