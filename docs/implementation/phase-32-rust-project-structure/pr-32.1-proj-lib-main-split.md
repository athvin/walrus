## Scope

**In scope**

- Capture the baseline below after every predecessor has merged.
- Modify only the canonical file list and perform this exact operation: Move each service's post-runtime application orchestration into `pub async fn run(config) -> Result` in an app module; keep argument/config loading, telemetry setup, runtime construction, exit reporting, and ExitCode mapping in main.
- Prove this postcondition: Each main is a thin owner of process-global setup, both library app functions compile under package tests, and behavior/order of bootstrap and shutdown is unchanged.

**Explicitly deferred** (do not build these here)

- Do not merge service modules, redesign config, or move subscriber/runtime ownership into libraries.
- Preserve CDC ordering `(commit_lsn, lsn)`, SQL/query bytes, public behavior, and existing error
  classification unless the required action explicitly names them.
