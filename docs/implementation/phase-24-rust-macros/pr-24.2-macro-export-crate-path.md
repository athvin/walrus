# PR 24.2 — Export a `string_enum!` macro from common and adopt it for the manifest enums

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Phase:** 24 — Rust macros · **Crates touched:** `common`, `control` · **Est. size:** M ·
> **Depends on:** PR 24.1 · **Unlocks:** PR 24.3

`#[macro_export]` appears **0 times** in the walrus tree, and after PR 24.1 the one surviving
`macro_rules!` (`num_builder!`) is file-local — so no macro in walrus is reachable across a crate
boundary. Meanwhile `control` hand-writes the identical string-enum boilerplate **four** times:
`as_str` + `FromStr` pairs at `manifest.rs:32/42` and `:67/75`, `reload.rs:35/43` and `:69/80`.
Between them those 8 impl blocks cover 13 variants whose DB-string literals are each written
**twice** — 26 literals for 13 facts — so `as_str()` and `FromStr` can silently disagree, which is
exactly the drift PR 8.2 retired at the *type* level and left standing at the *literal* level. This
PR builds the shared `string_enum!` macro in `common`, exports it with `#[macro_export]`, imports it
into `control` with a plain Rust-2018 path (`use common::string_enum;` — no `#[macro_use]`), and
converts `manifest.rs`'s two enums, collapsing 12 literals to 6 and deleting 4 impl blocks. The
persisted strings stay byte-identical, so no `.sql` file and no `.sqlx` cache entry moves.

## Why — learning objectives

- **`#[macro_export]` and Rust-2018 macro paths** — the attribute lifts a macro to the *crate root*
  regardless of which module defines it, and callers then `use common::string_enum;` like any other
  item. The legacy `#[macro_use] extern crate` form is order-sensitive, pollutes the global
  namespace, and stays at 0 occurrences in this tree.
- **One source of truth for a DB text contract** — `file_manifest.kind` / `.status` are plain `text`
  columns whose legal values live in exactly one Rust table, shared by sink, control and loader.
  After this PR that table is the macro invocation, written once per variant.

## Scope

**In scope**

- New `crates/common/src/string_enum.rs` defining `#[macro_export] macro_rules! string_enum`,
  generating from one variant table: the `enum` itself, an inherent `as_str(self) -> &'static str`,
  and `impl std::str::FromStr` with `type Err = String`.
- The first arm captures the enum's **doc comments** (`$(#[doc = $doc:literal])*` — `///` is already
  `#[doc = "…"]` by the time a matcher sees it) and hard-codes
  `#[derive(Debug, Clone, Copy, PartialEq, Eq)]` plus `pub`. Arbitrary attributes and visibility are
  PR 24.3's arm.
- Declare it in `crates/common/src/lib.rs` as a **private** `mod string_enum;` — `#[macro_export]`
  publishes the macro from the crate root by itself, so the module does not need to be `pub`.
- New `crates/common/src/string_enum_test.rs` (registered Go-style from `string_enum.rs`): invoke
  the macro on a throwaway enum and assert both directions round-trip, an unknown string is `Err`,
  and the trailing comma in the variant list is accepted.
- In `crates/control/src/manifest.rs`: `use common::string_enum;`, replace the two enums and their
  four impl blocks with two `string_enum!` invocations carrying the existing doc comments verbatim.
- Record in the invocation's comment that the strings are the persisted contract: `"snapshot"`,
  `"stream"`, `"spill"`, `"reload"`, `"ready"`, `"failed"`.

**Explicitly deferred** (do *not* build these here)

- **`reload.rs`'s two enums are not converted.** `ReloadFlavor` and `ReloadStatus` carry
  `#[derive(…, sqlx::Type)]` and `#[sqlx(rename_all = …)]` (`reload.rs:26-27`, `:57-58`) — attributes
  this PR's arm cannot capture or re-emit. PR 24.3 adds `$(#[$attr:meta])*` / `$vis:vis` and converts
  them.
- No `$crate::` path and no shared error-message helper — PR 24.4. This PR's generated `FromStr`
  builds its message inline.
- No `#[doc(hidden)] pub mod __private` — PR 24.5. No `compile_error!` fallback arm — PR 24.6.
- No `#[macro_use]` anywhere; the count stays 0.
- No change to any persisted string, no `.sql` edit, no `.sqlx` offline-cache regeneration (there is
  no Docker on this machine, and the SQL text is untouched, so the committed cache stays valid).
- No new dependency.

## Skeleton

```rust
// crates/common/src/string_enum.rs — new file.

//! `string_enum!`: one variant table -> a `Copy` enum plus its two-way `&'static str` mapping.
//!
//! walrus stores several closed sets as plain Postgres `text` (`file_manifest.kind`/`.status`,
//! `table_reload.flavor`/`.status`). Each needs the same pair of impls, and hand-writing them means
//! every legal string is typed twice — once in `as_str`, once in `FromStr` — so the two directions
//! can drift. This macro makes the variant table the single source of both.

/// Declare a `text`-column enum and its exact persisted strings in one table.
///
/// ```ignore
/// string_enum! {
///     /// Doc comments are captured and re-emitted onto the generated enum.
///     ManifestKind {
///         Snapshot => "snapshot",
///         Stream   => "stream",
///     }
/// }
/// ```
#[macro_export]
macro_rules! string_enum {
    (
        // `///` reaches a matcher already desugared to `#[doc = "…"]`, so a `:literal` capture
        // is enough here; PR 24.3 widens this to `$(#[$attr:meta])*`.
        $(#[doc = $doc:literal])*
        $name:ident {
            $($variant:ident => $text:literal),* $(,)?
        }
    ) => {
        $(#[doc = $doc])*
        #[derive(Debug, Clone, Copy, PartialEq, Eq)]
        pub enum $name {
            $($variant,)*
        }

        impl $name {
            /// The exact string persisted in the control DB.
            pub fn as_str(self) -> &'static str {
                match self {
                    $($name::$variant => $text,)*
                }
            }
        }

        impl ::std::str::FromStr for $name {
            type Err = ::std::string::String;

            fn from_str(s: &str) -> ::std::result::Result<Self, Self::Err> {
                match s {
                    $($text => Ok($name::$variant),)*
                    other => Err(todo!("uniform \"unknown <Name>: <other>\" message; PR 24.4 lifts \
                                        this behind $crate::unknown_variant")),
                }
            }
        }
    };
}

#[cfg(test)]
#[path = "string_enum_test.rs"]
mod tests;
```

```rust
// crates/control/src/manifest.rs — replacing :22-85. Doc comments carry over verbatim.

use common::string_enum;

string_enum! {
    /// The kind of a `file_manifest` row — the canonical enum for the `kind` text column, shared by
    /// the sink (which writes it; pg-sink re-exports this as `FileKind`) and the loader (which
    /// routes on it).
    ///
    /// `Spill` is a *single* streamed transaction written before its commit LSN was known (PR 4.3);
    /// the loader treats the file's `lsn_end` — not the per-row placeholder — as the authoritative
    /// `commit_lsn` for its rows. `Reload` chunk files (PR 6.1+) enter the same `(lsn_end, id)`
    /// claim order carrying a `reload_id`; `Snapshot`/`Stream` rows never set it.
    ManifestKind {
        Snapshot => "snapshot",
        Stream   => "stream",
        Spill    => "spill",
        Reload   => "reload",
    }
}

string_enum! {
    /// The lifecycle state of a `file_manifest` row: `Ready` to claim, or dead-lettered `Failed`.
    /// Applied rows are DELETED, never kept, so those are the only two persisted states.
    ManifestStatus {
        Ready  => "ready",
        Failed => "failed",
    }
}
```

// crates/common/src/string_enum_test.rs — new file. `string_enum!` is in textual scope here because
// `mod tests;` is declared *after* the definition in string_enum.rs.

use super::*;

string_enum! {
    /// A throwaway enum that exercises every generated item without touching a real contract.
    Signal {
        Green => "green",
        Amber => "amber",
        Red   => "red",   // trailing comma must be accepted by the `$(,)?` in the matcher
    }
}

#[test]
fn round_trips_every_variant_both_directions() {
    for (v, s) in [
        (Signal::Green, "green"),
        (Signal::Amber, "amber"),
        (Signal::Red, "red"),
    ] {
        assert_eq!(v.as_str(), s);
        assert_eq!(s.parse::<Signal>(), Ok(v));
    }
}

#[test]
fn rejects_an_unknown_string() {
    assert!("chartreuse".parse::<Signal>().is_err());
    assert!("".parse::<Signal>().is_err());
    // Case matters — the DB stores exactly the lowercase form.
    assert!("Green".parse::<Signal>().is_err());
}

#[test]
fn generated_enum_is_copy_and_eq() {
    let a = Signal::Amber;
    let b = a; // `a` is still usable => Copy, which `as_str(self)` requires.
    assert_eq!(a, b);
    assert_eq!(todo!("format!(\"{a:?}\")"), "Amber");
}

## Hints & gotchas

- **`#[macro_export]` ignores the module tree.** The macro is defined in `string_enum.rs` but lands
  at `common`'s crate root, so callers write `use common::string_enum;`. Keep the module private
  (`mod string_enum;`): if you make it `pub`, the name `common::string_enum` exists in *both* the
  macro namespace and the type namespace, which compiles but reads as an ambiguity to every future
  reader.
- **`///` is already `#[doc = "…"]` when the matcher runs.** That is why `$(#[doc = $doc:literal])*`
  matches a multi-line doc comment and why re-emitting `$(#[doc = $doc])*` reproduces it. Do not try
  to capture `///` as tokens.
- **Textual scope inside the defining crate.** Within `common` itself the macro is only visible
  *after* its `macro_rules!` item, which is why `#[cfg(test)] mod tests;` goes at the **bottom** of
  `string_enum.rs`. (From another crate the `use` path has no such ordering rule.)
- **`as_str(self)` takes `self` by value**, so the generated enum must be `Copy` — that is why the
  arm hard-codes the derive list. Both call sites (`f.kind.as_str()` at `manifest.rs:136`) rely on
  it, and `ManifestRow`/`NewManifestFile` store the enum by value.
- **The rejection message changes text, not behaviour.** Today it is `"unknown manifest kind: {other}"`;
  the generated one is uniform across every enum. Grep first — no test in the tree asserts that
  string, only `.is_err()` — and note it in the PR body. `ControlError::Decode(String)` (`db.rs:40`)
  still swallows whatever `FromStr` produces, so `is_terminal()` is unaffected.
- **Fully-qualify std paths inside the expansion** (`::std::str::FromStr`, `::std::string::String`).
  The expansion is pasted into `control`'s namespace, and a caller that happens to shadow `String`
  would otherwise break the macro. `$crate` for *walrus* items arrives in PR 24.4.
- **Keep `pub use` lists honest.** `control/src/lib.rs:22-25` re-exports `ManifestKind` /
  `ManifestStatus` from `manifest`; macro-generated items are ordinary items, so that line needs no
  change — verify it still compiles rather than assuming.
- Tests are Go-style sibling files, never inline `mod tests {}`. `unwrap`/`expect` are denied in
  production by `[workspace.lints.clippy]` and re-allowed in tests by `clippy.toml`; `clippy::all`
  and `warnings` are already `deny`. Any new dependency would have to clear `cargo deny`
  (advisories, the 8-license allow-list, bans) — none is needed here.
- Do not touch any `.sql` file or the committed `.sqlx` offline cache; there is no Docker on this
  machine to regenerate it. The persisted strings are byte-identical, so nothing needs it.
