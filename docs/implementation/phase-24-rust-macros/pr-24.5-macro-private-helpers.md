# PR 24.5 — Hide the macro's runtime helper behind `#[doc(hidden)] pub mod __private`

> **Status:** 📋 Planned <!-- flip to "✅ Done — <PR url>" when it merges -->

> **Readiness:** audited · **Outcome:** change
>
> **Gates:** fmt,clippy,test · **Test packages:** common,control

> **Phase:** 24 — Rust macros · **Crates touched:** `common` · **Est. size:** S ·
> **Depends on:** PR 24.4 · **Unlocks:** PR 24.6

`#[doc(hidden)]` appears **0 times** in Rust source and there is no `__private` module anywhere,
while `common` is the foundation used by `control`, `pg-sink`, `pg-to-arrow`, `loader`, and the
`tests/e2e` harness. Its crate root currently has 13 `pub mod` statements and 10 root `pub use`
statements. Nine of those re-export statements are the established flat API; PR 24.4 added the
tenth solely so generated code could reach the generic typed adapter
`unknown_variant<E>(column, input, make_error) -> E` as `$crate::unknown_variant(..)` from inside
`control`.

That helper must be `pub`, but it is not a general-purpose error formatter or a new error contract.
It forwards the macro's exact `$column` and rejected input to the caller-selected `<$error>::new`,
so all four production expansions still return `ParseEnumError { column, input }` and
`ControlError::Decode(#[from] ParseEnumError)` remains typed. This PR changes only how generated
code reaches that same adapter: move its re-export behind the serde/thiserror convention of one
`#[doc(hidden)] pub mod __private`, lengthen the `$crate` path by one segment, and keep the helper's
signature, body, inputs, returned type, and every invocation unchanged.

## Why — learning objectives

- **`#[doc(hidden)] pub mod __private`** — the ecosystem convention (serde, thiserror, and derive
  crates) for items that must be `pub` so macro call sites can name them, but that carry no
  stability promise. Visibility keeps them reachable; the attribute and the `__` prefix carry the
  "not API" signal.
- **Keeping a foundation crate's surface honest** — four crates plus the e2e harness compile against
  `common`; the typed adapter is macro plumbing, not a flat API that callers should discover.
- **Privacy does not require erasing types** — relocating the re-export must preserve the caller's
  `ParseEnumError` constructor, exact column/input data, and typed terminal wrapper byte-for-byte.

## Hints & gotchas

- **Hiding is a convention, not a visibility or type change.** `__private` and the re-exported
  function must be `pub` or the expansion cannot name them from `control`; `#[doc(hidden)]` only
  removes them from rendered docs. The generic adapter must continue returning the caller-selected
  `E` rather than a formatted `String`.
- **The constructor remains a caller token.** `<$error>::new` resolves where the invocation lives;
  only the adapter path resolves through the defining crate. Do not make `common` name
  `control::ParseEnumError`, add an accepted-value list, or change the macro's invocation API.
- **`$crate::__private::…` is a crate-root path**, so the module must be declared in `lib.rs`, not
  nested inside `string_enum.rs`. The function stays in the private `string_enum` module; only its
  re-export moves.
- **A public hidden module is not a semver promise here.** walrus publishes no workspace member;
  `__private` is still deliberately exempt from stability expectations by convention. PR 24.8 owns
  the full publication evidence, so do not add a policy document in this task.
- **`pub use` out of a private module is valid.** The private `mod string_enum;` remains the
  implementation boundary, while the public hidden namespace is the generated-code access seam.
- **`grep` the doc index, not the whole `target/doc` tree.** `all.html` is rustdoc's all-items page;
  source listings and search indexes can still contain the identifier.
- **Do not add `#[doc(hidden)]` anywhere else.** The single occurrence is the audit signal. The
  module-doc convention note should name `__private` without repeating the attribute text.
- Tests are Go-style sibling files; `unwrap`/`expect` are denied in production and re-allowed in
  tests by `clippy.toml`; `clippy::all` and warnings are denied workspace-wide. No dependency is
  needed. Keep all SQL and `.sqlx` files byte-identical.
