## Why — learning objectives

  exceptions in the source rule rather than applying its example mechanically.
- Preserve the project-specific trade-off in this audit: Transaction and batch buffers transfer ownership into sealed work with `mem::take`; draining would retain borrows or copy elements and cannot reuse capacity across the ownership boundary.
